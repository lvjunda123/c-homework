========================================
  作业怎么传到 GitHub —— 看这里
========================================

【一】最简单的方法（推荐）

  1. 在这个文件夹里改你的作业代码
  2. 改完，双击：提交作业.bat
  3. 黑窗口里输入一句说明，比如「第9次作业 冒泡排序」
     （直接按回车也行，会写成「更新作业」）
  4. 看到「完成！作业已经上传」就好了

  注意：第 3 步输入中文后，按回车提交；如果窗口一闪就没了，
  说明出错了，把窗口截图保存下来。

【二】上传后去哪看

  浏览器打开：
  https://github.com/lvjunda123/c-homework

  点进某个文件夹，就能看到你的 main.cpp 代码。

  ★ 重点：在这个网页上看到代码 = 真的存到云端了。
    只在电脑 D:\homework 里改、没有上传，就不算备份。

【三】每个文件夹是什么

  01-hello-variables            变量输出
  02-print-0-to-9               循环输出 0-9
  03-name-and-age               输入姓名年龄
  04-array-reverse              数组逆序
  05-perfect-numbers            完数
  06-factorial                  阶乘
  07-divisible-by-3-ending-6    能被3整除且个位是6
  08-alternating-series         交错级数求和

【四】以后加新作业

  在 D:\homework 里新建一个文件夹，比如 09-bubble-sort，
  把 main.cpp 放进去，然后双击 提交作业.bat 就行。

【五】不要做的事

  x 不要把 .exe 文件放进去（.gitignore 会自动忽略，不用管）
  x 不要删掉 .git 文件夹（删了就不是仓库了，历史记录全没）
  x 不要把作业放进 D:\ds（那是软件安装目录，重装会丢）

【六】改了想反悔怎么办

  跟我说「我想撤回上一次提交」，我来帮你恢复。
  不要自己乱删文件。
